# Стратегия "Адаптивный Ценовой Канал" с фильтром по волатильности

## Описание стратегии

Стратегия **R3_PriceChannel** — это системный тренд-фолловинг алгоритм, основанный на адаптивном ценовом канале, который динамически подстраивается под силу текущего тренда с помощью индекса ADX (Average Directional Index). Стратегия автоматически фильтрует инструменты по волатильности и использует опциональный фильтр скользящей средней для подтверждения направления тренда.

**Основа**: улучшенная версия стратегии AlgoStart3PriceChannel из платформы OSEngine (автор: AlexWan).

---

## Как она работает

### 1. Адаптивный Ценовой Канал с ADX

Ключевая особенность стратегии — **динамическое изменение ширины канала в зависимости от силы тренда**:

1. **Расчёт ADX**: Анализируется ADX за последние N периодов (параметр `pc_adx_length`, по умолчанию 50)
2. **ADX показывает силу тренда**:
   - **Высокий ADX** (> 50) = Сильный тренд → канал сужается
   - **Низкий ADX** (< 20) = Слабый тренд → канал расширяется
3. **Адаптивная длина канала**:
   ```
   channel_length = max(ratio / ADX, 1)
   Параметр ratio по умолчанию = 840
   ```

   Примеры:
   - Если ADX = 100 (сильный тренд): `length = 840 / 100 = 8.4` → канал очень узкий, реагирует быстро
   - Если ADX = 21 (средний тренд): `length = 840 / 21 ≈ 40` → нормальный канал
   - Если ADX = 10 (слабый тренд): `length = 840 / 10 = 84` → канал широкий, фильтрует шум

4. **Построение канала**:
   ```
   Верхняя граница = Максимум цены за последние channel_length свечей
   Нижняя граница = Минимум цены за последние channel_length свечей
   ```

```
Представление канала:
        ┌─────── Верхняя линия (гипотеза покупателей)
        │
   ────┼────────── Цена закрытия
        │
        └─────── Нижняя линия (гипотеза продавцов)

- При сильном тренде канал узкий → легче входить в позицию
- При слабом тренде канал широкий → нужны более сильные сигналы
```

### 2. Фильтр по волатильности

Стратегия разделяет инструменты на три группы по волатильности (кластеры):

**Кластеризация** (параметр `cluster_lookback` = 100 периодов):
1. Анализируются последние 100 свечей
2. Все инструменты сортируются по среднему диапазону цены
3. Инструменты делятся на три равные группы:
   - **Кластер 1** (33%): Низкая волатильность — стабильные, предсказуемые инструменты
   - **Кластер 2** (33%): Средняя волатильность — баланс между риском и доходом
   - **Кластер 3** (34%): Высокая волатильность — активные инструменты с крупными движениями

**Выбор кластера** (параметр `volatility_cluster` = 1, 2 или 3):
- При торговле в выбранном кластере риски более согласованы
- Стратегия проще адаптировать под конкретный кластер
- Пример: для консервативной торговли выбирается кластер 1, для агрессивной — кластер 3

### 3. Фильтр по SMA (опциональный)

Для подтверждения восходящего тренда может использоваться скользящая средняя:

**SMA фильтр** (параметр `sma_filter` = True, `sma_period` = 70):
- Расчитывается 70-периодная простая скользящая средняя от цены закрытия
- Вход в позицию разрешён только если **SMA растёт** (SMA[0] > SMA[-1])
- Служит подтверждением долгосрочного восходящего тренда
- Дополняет краткосрочный сигнал от канала долгосрочным контекстом

### 4. Управление позициями

**Размер позиции** (параметр `volume_pct` = 10%):
- Каждая позиция занимает 10% от размера портфеля
- Автоматически адаптируется к текущему балансу счёта
- При рост баланса → размер позиции растёт, при убытках → размер уменьшается

**Лимит открытых позиций** (параметр `max_positions` = 10):
- Максимум 10 позиций одновременно
- Предотвращает чрезмерную концентрацию капитала
- Защищает от "рассеивания" на слишком много инструментов

## Логика входа в позицию

```
1. Проверка времени торговли → в пределах торговых часов? ✓
2. Проверка дня недели → торговый день (Пн-Пт)? ✓
3. Проверка позиции → позиция уже открыта? ✗ (нужно быть в денежном)
4. Проверка волатильного кластера → инструмент в нужном кластере? ✓
5. Проверка лимита позиций → не превышен ли лимит (макс. 10)? ✓
6. Проверка канала → верхняя полоса рассчитана? ✓
7. Пробой канала → цена закрылась выше верхней полосы? ✓
8. SMA фильтр → SMA растёт? ✓ (если фильтр включён)
9. → ВХОД: Открыть длинную позицию размером 10% портфеля
```

**Описание сигнала входа**:

Сигнал генерируется, когда цена закрытия **пересекает верхнюю границу адаптивного канала сверху вниз**:

```
Цена
      ╔═════════╗  ← Верхняя граница
      ║         ║
      ║  КАНАЛ  ║─→ Когда цена коснулась этой линии
      ║         ║   → ПОКУПАЕМ (вход на пробой)
      ╚═════════╝  ← Нижняя граница

Смысл сигнала:
- Пробой верхней границы = цена выходит в новую силу
- Это начало нового импульса вверх
- На сильном тренде (высокий ADX) канал узкий → сигналы частые
- На слабом тренде (низкий ADX) канал широкий → сигналы редкие (более надёжные)
```

---

## Логика выхода из позиции

Стратегия использует **простой выход**: закрытие всей позиции, когда цена коснулась нижней границы канала.

**При удержании позиции** отслеживается нижняя полоса канала:

```
Цена
      ╔═════════╗  ← Верхняя граница (уже пересекли)
      ║         ║
      ║  КАНАЛ  ║
      ║         ║
      ╚═════════╝  ← Нижняя граница
           ↓
         ВЫХОД! (когда цена коснулась)
```

**Критерии закрытия позиции**:
```
Если: цена закрытия <= нижняя граница канала
→ ВЫХОД: Закрыть позицию полностью по текущей цене
```

**Смысл логики выхода**:
- Нижняя граница канала = уровень, где предложение начинает превышать спрос
- Выход ниже канала = сигнал того, что импульс исчерпан
- Позиция должна быть закрыта для сохранения прибыли или ограничения убытков
- На сильном тренде (узкий канал) выход происходит ближе к максимуму
- На слабом тренде (широкий канал) выход может быть с меньшей прибылью

## Ключевые параметры

| Параметр | Значение | Диапазон | Описание |
|----------|----------|----------|---------|
| `pc_adx_length` | 50 | 5-300 | Период для расчета ADX и ширины канала |
| `pc_ratio` | 840 | 5-2000 | Коэффициент для расчета адаптивной длины |
| `sma_filter` | True | True/False | Включить фильтр скользящей средней |
| `sma_period` | 70 | 100-300 | Период SMA для фильтра тренда |
| `volume_pct` | 10 | 1-50 | Размер позиции в % от портфеля |
| `max_positions` | 10 | 1-20 | Максимум одновременных позиций |
| `volatility_cluster` | 2 | 0-3 | Выбор кластера (0 = без фильтра, 1-3 = определённый кластер) |
| `cluster_lookback` | 100 | 10-300 | Период для расчета кластеров волатильности |
| `trade_start_tm` | 10:05 | - | Начало торговой сессии |
| `trade_end_tm` | 18:00 | - | Конец торговой сессии |
