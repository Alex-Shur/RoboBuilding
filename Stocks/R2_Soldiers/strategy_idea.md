# Стратегия "Три Солдата" с адаптацией по волатильности

## Описание стратегии

Стратегия **R2_Soldiers** — это системный тренд-фолловинг алгоритм, основанный на классическом паттерне "Три Восходящих Солдата" (Three White Soldiers). Стратегия автоматически адаптирует критерии входа в зависимости от текущей волатильности инструмента, что делает её универсальной для торговли активами с разными характеристиками.

**Основа**: улучшенная версия стратегии AlgoStart2Soldiers из платформы OSEngine (автор: AlexWan).

---

## Как она работает

### 1. Поиск паттерна "Три Солдата"

Стратегия ищет **три последовательных бычьих свечи**, где:
- **Все три свечи восходящие**: close > open (без нижних теней)
- **Растущий паттерн**: каждая следующая свеча обычно выше предыдущей
- **Требуемая высота**: высота всех трёх свечей (от минимума к максимуму) должна соответствовать критериям волатильности

```
Структура паттерна:
  close[0]  ┌─ Новейшая свеча (самая свежая)
            │
  close[-1] ├─ Средняя свеча  
            │
  close[-2] └─ Самая старая свеча

Все три: close > open (бычьи свечи)
```

### 2. Адаптация по волатильности

Ключевая особенность стратегии — **динамическое определение минимальной высоты паттерна** на основе текущей волатильности:

1. **Расчёт волатильности**: Анализируются последние 7 дней (параметр `days_volatility_adaptive`)
2. **Дневная волатильность**: Для каждого дня вычисляется `(max_high - min_low) / min_low * 100%`
3. **Средняя волатильность**: Берётся среднее значение за 7 дней
4. **Минимальная высота паттерна**: `средняя_волатильность * 80% = требуемая_высота`
   - На низкой волатильности → требуется небольшой паттерн (легче входить)
   - На высокой волатильности → требуется крупный паттерн (меньше ложных сигналов)

### 3. Дополнительные фильтры входа

**SMA фильтр** (если включен):
- Проверяется 150-периодная скользящая средняя
- Вход разрешён только если SMA растёт (`SMA[0] > SMA[-1]`)
- Это подтверждает, что стратегия находится в восходящем тренде

**Кластеризация волатильности**:
- Инструменты разделяются на 3 группы по волатильности (низкая/средняя/высокая)
- Можно торговать только инструменты выбранного кластера
- Полезно для управления рисками: низкая волатильность = более стабильные прибыли, высокая = более крупные движения

### 4. Управление позициями

**Размер позиции**:
- Параметр `volume_pct = 10%` означает, что каждая позиция занимает 10% от размера портфеля
- Автоматически адаптируется к текущему счёту

**Лимит открытых позиций**:
- Максимум 10 позиций одновременно
- Предотвращает чрезмерное рассеивание капитала

## Логика входа в позицию

```
1. Проверка времени торговли → во время выбранных часов? 
2. Проверка волатильного кластера → инструмент в нужном кластере? 
3. Проверка позиции → позиция уже открыта? 
4. Проверка лимита → не превышен ли лимит открытых позиций? 
5. Поиск паттерна → три восходящих свечи нужной высоты? 
6. SMA фильтр → средняя растёт? 
7. → ВХОД: Открыть длинную позицию размером 10% портфеля
```

---

## Логика выхода из позиции

Стратегия использует **двухуровневый выход**: Stop Loss и Take Profit, рассчитанные от высоты паттерна входа.

**При вступлении** вычисляется высота всех трёх свечей:
```
pattern_height = close[0] - open[-2]
```

**Stop Loss** (защита от убытков):
```
stop_price = entry_price - (pattern_height * 106% / 100)
Пример: Если паттерн высотой 1000 пипс, стоп ставится на 1060 пипс ниже входа
```

**Take Profit** (фиксация прибыли):
```
take_price = entry_price + (pattern_height * 185% / 100)
Пример: Если паттерн высотой 1000 пипс, тейк ставится на 1850 пипс выше входа
```

При достижении любого из уровней позиция закрывается.

## Параметры стратегии

| Параметр | Значение | Описание |
|----------|----------|---------|
| `sma_filter` | True | Включить фильтр по SMA |
| `sma_period` | 150 | Период скользящей средней |
| `volume_pct` | 10 | Размер позиции (% портфеля) |
| `max_positions` | 10 | Максимум одновременных позиций |
| `volatility_cluster` | 3 | Кластер волатильности (1=низкая, 2=средняя, 3=высокая) |
| `cluster_lookback` | 80 | Период для расчета кластеров |
| `days_volatility_adaptive` | 7 | Дней для расчета волатильности |
| `height_soldiers_vola_percent` | 80 | Требуемая высота как % волатильности |
| `proc_height_take` | 185 | Take Profit как % высоты паттерна |
| `proc_height_stop` | 106 | Stop Loss как % высоты паттерна |
| `trade_start_tm` | 10:05 | Начало торговой сессии |
| `trade_end_tm` | 18:00 | Конец торговой сессии |
| `trade_weekdays` | [0,1,2,3,4] | Дни недели (пн-пт) |

## Преимущества стратегии

 - **Адаптивность** — автоматически подстраивается под волатильность  
 - **Простота** — классический паттерн, легко понять и отследить  
 - **Фильтры** — SMA и волатильные кластеры снижают ложные сигналы  
 - **Управление рисками** — чёткие стоп-лоссы и тейк-профиты  
 - **Масштабируемость** — работает с несколькими инструментами одновременно  
 - **Производительность** — Numba компилирует горячие циклы для скорости  

---

## Риски и особенности

 - **Боковой рынок** — паттерн может даваться часто на боковом движении  
 - **Волатильность** — высокая волатильность может привести к ложным пробоям

## Типичный цикл торговли

```
Время: 10:05-18:00 (московское время, пт-пт)

1️⃣ Проверка условий (кластер, время, лимиты)
   ↓
2️⃣ Обнаружение трёх восходящих свечей нужной высоты
   ↓
3️⃣ Вход в длинную позицию (10% портфеля)
   ↓
4️⃣ Ожидание закрытия позиции (стоп или тейк)
   ↓
5️⃣ Выход и регистрация прибыли/убытка
   ↓
6️⃣ Повтор со следующего паттерна
```
